# Delegated access: the document, the branches and the skill

`docs/delegated-access-functional-requirements.md` is the single authoritative document for Login.gov's
delegated-access work. It is organized by feature branch: sections 1 to 14 each cover one branch of the
stack in merge order, with the branch's objective, the functional requirements it owns, the protocol
rows it implements, what was built, the decisions behind it and how to review it. Section 15 covers the
base branch and work outside this repository, section 16 is the decisions log, and the appendices hold
the traceability matrix (A, generated), the stack and review procedure (B), environment-specific
pieces (C), the performance review and open items (D), the foundation review (E) and terms (F).

`docs/delegated-access-implementation-plan.md` is kept as a historical record of how the work was
planned and built through 2026-10-13. It is not maintained; the single document above supersedes it.

## Reading order

- A reviewer of one pull request: Appendix A to find the rows, then that branch's section.
- A newcomer: the front matter, Appendix B for the stack, then sections 1 to 14 in order.
- Anyone changing a requirement: section 16 for the rationale that already exists, then the skill's
  update protocol.

## The branch stack

```

 ├─  7. delegated-access-token-lifecycle    section 7   refresh rotation, revocation, suspension

 ├─  9. delegated-access-saml-assertions    section 9   SAML assertions as an issued token type
 ├─ 10. delegated-access-operations         section 10  discovery and operational metadata
 ├─ 11. delegated-access-billing-reporting  section 11  billing rows and reports

```

Each branch is reviewed as the diff against the one below it and merged bottom-up by fast-forward;
Appendix B and the skill's `references/review-and-merge.md` give the procedure.

## The traceability matrix

Appendix A is generated by the skill's `scripts/build_index.py` between markers in the document and
must not be edited by hand. It maps every functional requirement row to its section and branch, the
protocol rows that implement it and the decisions that shaped it, and lists the rows satisfied by the
foundation or outside this repository.

## The skills

`.claude/skills/login-delegated-access` is the project skill for agents and people working on these
branches: a short `SKILL.md` maps each activity to the one or two references to load; `references/`
holds the generated indexes, the per-branch context, RFC digests, the interview and update protocol,
the review-and-merge rules and the local and sandbox runbooks; `scripts/` holds the generator, the
twin sync, the self-check and the local stack helpers. `interview` and `login-billing` sit beside it.
`.agents/skills` is their byte-identical twin, kept by `scripts/sync_twins.sh` and checked by
`scripts/check.sh`.
